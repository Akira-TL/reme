# Reme —— 小米原生态的银发家庭 AI 关怀助手

第七届小米集团黑客马拉松 · 高校赛道 · Xiaomi MiMo 竞赛单元参赛项目。

**一句话定位**：Reme 是可植入现有家庭摄像与语音设备的隐私关怀智能层——端侧把真实画面转成姿态与事件，由 Xiaomi MiMo 判断是否介入、如何沟通，再把确认后的需求转成家属可执行的行动。

> **看见需要，不看见隐私。**

## 架构一览

```
上游 · 本地感知        中心 · 姿态与事件资产          下游 · 行为理解与行动
像素 → 姿态关键点  →   去身份化结构化事件   ───→   规则引擎 → MiMo 认知 → 家属行动卡片
       └──────────── 事件触发的最小关键帧/短视频 ───→ MiMo 视觉判断
（默认不额外留存）      （发送显式、最小、可观察）    （高风险由确定性状态机兜底）
```

隐私不是拒绝所有视觉信息，而是限制视觉信息的使用方式：系统默认以骨架和事件工作；只有当前判断需要时，才将最少关键帧或最短视频片段显式发送给 MiMo，家属端仍以事件、摘要和行动为默认交付。
