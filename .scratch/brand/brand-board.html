01

这个产品是什么

What Reme Is

家人需要"被看见"的安全，老人需要"不被观看"的尊严。Reme 不在两者间选边，而是改变"看"这个动作：真实画面止于端侧，进入 Agent 的是事件，交付给家属的是行动。

存量摄像头
纯软件接入，不买新硬件；真实画面止于端侧
火柴人骨架
MoveNet 17 关键点，没有面孔、没有画面
结构化事件
姿态、转变、时长——骨架再化作纯文本事实
MiMo 认知
判断是否介入、怎么开口；规则状态机兜底安全
先问本人
自然开口、可拒绝；授权之前不惊动任何人
家属行动卡片
确认过的需要，变成可执行的下一步与回执

冷的感知，交出暖的行动。数据每走一步，隐私少一分，语义多一分——这条流水线既是架构图，也是品牌观。

表达断点

老人不愿说、不会说，突发时说不出。
解法：主动开口，把没说出口的需要问出来。

判断断点

设备发现变化，却不知道值不值得打扰。
解法：MiMo 读懂异常背后的原因，规则守住风险。

行动断点

家属收到异常，却不知道先做什么。
解法：行动卡片给出具体下一步，直到处理闭环。

02

名字：Re·me 的三种读法

Name Story

读 ree-mee，重音在后。书写恒为 Reme——不与 Redmi 混淆的口诀：Redmi 重音在前，Reme 重音在"我"。

Remember me

被记得

独居的日子里，有人记得你午饭吃得顺不顺口、夜里起了几次身。

Re: me

一封关于我的回信

"Re:" 是回信的前缀。每张行动卡片，都是替说不出口的老人写下的一封"关于我"的信；家属的"已处理"，就是回信。

重音在 me

主语是老人本人

先问本人、本人可拒绝、授权在本人。系统再聪明，"我"始终是这个家的第一人称。

03

三支柱：看懂 · 克制 · 出现

Pillars

路演记忆点直接升格为品牌支柱——每根柱子都有可演示的证据，不是形容词。

看懂

不止发现异常，还理解原因。

证据：长时间静坐 → 自然开口 → 「牙疼，饭咬不动」被听见；卡片绑定老人原话。

克制

能不看就不看，能不吵就不吵。

证据：骨架化呈现；默认零像素出网，视觉上下文按需、最小、可审计；开口只问一件事，可拒绝。

出现

该出现时，一定出现。

证据：超时规则升级，MiMo 不可取消；行动卡片给出具体下一步——对话是模型的形状，安全是规则的形状。

04

标志

Logo
  • 无面孔的头：17 个关键点中 5 个面部点被折叠成一个空圆——logo 本身就是隐私承诺的图解。
  • 12 个关节点：肩肘腕髋膝踝，与感知层数据一一对应。
  • 暖色的腕点：先开口问候的那只手——询问先行。
  • 怀抱弧：摄像头视野锥倒过来，是一只托住的手，也是一条微笑线。
不加五官表情弧不改成对勾护红不做主色深底不用纯白

字标 Reme 为单线字形，笔画与火柴人肢体同宽——名字和人是同一种笔画写出来的。

05

色彩：双温层

Color

不是从零发明，而是收编仓库里已长出的工程视觉（深青黑 + 薄荷青 + 琥珀），再补上一个温度层。感知层冷、关怀层暖，两层交接的瞬间——骨架化作行动卡片——就是品牌时刻。

07

语言系统

Voice

品牌人格：一位懂分寸的晚辈——不是保安（不盯着）、不是医生（不诊断）、不是客服（不套话）。多数时候安静，开口只问一件事，答应了的事一定办到。

老人端 · 晚辈
"王奶奶，今天午饭吃得还顺口吗？"
"好的，那不打扰您了。"

一次只问一件事；口语短句；称呼按 persona 钉死，不换称谓。

家属端 · 转达者
"妈妈说'牙疼，饭咬不动'。建议今晚打个电话。"

事实先行，不贩卖焦虑；引语只用老人原话（服务端绑定）；每条信息都带下一步。

评委场 · 工程团队
"跌倒确认窗口内无响应，规则直接升级——模型再聪明，也无权取消这一步。"

主张挂证据；不承诺没测过的数字。

说

  • 守护 / 留意 / 确认 / 转达
  • 骨架 / 姿态 / 事件
  • 按需最少地看 / 按需取证
  • 疑似跌倒 / 需要确认
  • 提醒家人 / 请家人来电

不说

  • 监控 / 盯着 / 抓拍 / 追踪产品自我定义即非监控（MoveNet 适用范围红线）
  • 画面 / 录像（作为交付物时）交付给家属的是行动，不是画面
  • "原始画面永远不进 MiMo"ADR-0003 已建立按需最小视觉上下文，绝对化表述禁用
  • 检测到跌倒 / 诊断 / 准确率 X%无标注集不出数字；不做医疗宣称
  • 报警 / 呼救系统（对老人端）对老人的语言永远是"家人"，不是"警"

卡片即品牌。行动卡片是"出现"支柱的实体，也是评委与家属最常看到的品牌载体：六要素固定次序，原话永远带引号、用老人自己的字。

09

红线

Hard Lines
  1. 隐私表述一律走"显式、最小、可观察"的口径，禁用"永不 / 绝不"句式。ADR-0003；D spec 禁止项
  2. 不宣称基于 Miloco 二次开发；对外传播不做"小米 / 米家"品牌背书暗示（比赛语境内"小米原生态"作生态位描述可用）。Miloco 许可证红线，情报-MiMo-API §7
  3. 不做医疗器械与诊断暗示；未标注数据不出百分比，不承诺跌倒检测率。CONTEXT non-goals；ADR-0006 不能宣称清单
  4. 演示降级必须可见，record 不伪装成实时——诚实本身是品牌的一部分。C 验收约束
