# 姿态分类可行性实验协议

- 日期：2026-08-01
- 状态：等待样本视频
- 目标：判断视频中的人体骨骼是否足以支持隐私保护下的姿态状态分类和跌倒式转变分类。

## 1. 技术分层

实验必须把以下四层分开评估：

1. **视频解码**：本地读取视频帧。
2. **姿态提取**：将每帧转换为人体关键点与关键点置信度。
3. **分类**：从关键点判断静态姿态与时间序列转变。
4. **MiMo 交互**：消费结构化分类结果，生成说明、询问或摘要。

任意一层成功都不能替代对其他层的验证。

## 2. 隐私输出要求

实验过程允许本地解码原视频，但默认展示和保存的产物只能是：

- 空白背景上的骨骼；
- 不可轻易辨认身份的轮廓；
- 强模糊或像素化画面；
- 结构化标签、置信度和时间线。

不得默认把原始帧发送给 MiMo，不得为调试静默导出原始帧。

## 3. 标注单位

### 3.1 静态姿态

按连续时间段标注，不逐帧人工标注。第一版候选标签：

| 标签 | 工作定义 | 排除项 |
|---|---|---|
| `standing` | 躯干总体直立，主要由双腿或单腿支撑 | 走动仍可归入直立状态，但需额外记录运动标记 |
| `sitting` | 髋部由椅面、床沿或其他表面支撑，膝部通常弯曲 | 深蹲、跪姿不归入坐姿 |
| `lying` | 躯干整体接近水平并由床、地面或沙发支撑 | 短暂弯腰或俯身不归入躺卧 |
| `bending_or_crouching` | 躯干明显前倾、下蹲、跪姿或低位动作 | 不应被自动当成跌倒 |
| `unknown` | 人体离画、严重遮挡、多人重叠或关键点不足 | 不强行归入最近标签 |

可额外记录一个独立的 `moving` 布尔属性，避免把“走路”混入姿态标签体系。

### 3.2 时间序列转变

按事件时间窗标注：

| 标签 | 工作定义 |
|---|---|
| `normal_transition` | 正常坐下、起身、躺下、翻身或下蹲等有控制的转变 |
| `fall_like_transition` | 短时间内由较高/直立状态快速转为低位或水平状态，具有明显失衡或冲击式变化 |
| `uncertain_transition` | 遮挡、镜头切换或动作语义不足，无法可靠区分正常转变和跌倒式转变 |

跌倒式事件至少需要一个时间窗口，不允许仅凭单帧 `lying` 判定。

## 4. 候选姿态提取器

首轮比较：

1. **MediaPipe Pose Landmarker**：视频模式输出 33 个归一化和世界坐标关键点，可选人体分割掩码。
   - 官方文档：https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker
2. **MoveNet SinglePose Lightning**：输出 17 个关键点，官方定位为低延迟版本。
   - 官方教程：https://www.tensorflow.org/hub/tutorials/movenet

同一视频、同一帧采样策略、同一机器上比较，不能用各自最有利的不同输入条件。

## 5. 分类路线

### 5.1 透明几何基线

先建立一个可解释基线，候选特征包括：

- 肩部中点与髋部中点形成的躯干方向；
- 髋、膝、踝的垂直排序；
- 躯干、股骨和小腿夹角；
- 骨骼包围盒长宽比；
- 人体中心高度；
- 关键点可见度和缺失比例；
- 关键点速度、加速度与短窗变化量。

该基线用于判断哪些类别可由简单证据区分，并作为后续学习模型的对照，不预设固定阈值。

### 5.2 轻量静态分类器

当标注样本足够时，使用归一化骨骼特征训练轻量模型，例如逻辑回归、随机森林或小型 MLP。必须按视频片段或人物划分训练与测试，不能随机打散相邻帧造成数据泄漏。

### 5.3 时序分类器

只有静态姿态和关键点连续性通过后才比较时序方法。候选优先级：

1. 特征窗口 + 轻量分类器；
2. 小型 1D CNN、TCN 或 LSTM；
3. 数据量和时间充足时才考虑 ST-GCN 或 PoseC3D。

ST-GCN 将骨骼建模为空间—时间图，证明了骨骼序列可用于动作识别；PoseC3D 使用时空热图并强调对姿态噪声的鲁棒性。但这些论文不能替代对本项目视频和类别的实测。

- ST-GCN：https://aaai.org/papers/12328-spatial-temporal-graph-convolutional-networks-for-skeleton-based-action-recognition/
- PoseC3D：https://openaccess.thecvf.com/content/CVPR2022/html/Duan_Revisiting_Skeleton-Based_Action_Recognition_CVPR_2022_paper.html

## 6. 评价指标

静态姿态：

- 每类 precision、recall、F1；
- 混淆矩阵；
- `unknown`/拒判比例；
- 标签抖动次数；
- 从遮挡恢复到稳定标签所需时间。

时间序列转变：

- 每个事件是否检出；
- 误报的正常转变数量；
- 事件检测延迟；
- `uncertain_transition` 比例；
- 正常躺下与跌倒式转变的混淆。

姿态提取：

- 有效人体检测帧比例；
- 关键点缺失率；
- 明显跳点数量；
- 平均与 P95 单帧耗时；
- CPU、内存和输出稳定性。

不得只报告整体 accuracy，也不得把同一段视频的相邻帧同时放进训练集和测试集。

## 7. MiMo 输入候选

分类 Gate 通过后，MiMo 的最小候选输入可包含：

- 当前姿态及分类置信度；
- 最近若干秒姿态序列；
- `fall_like_transition` 等候选事件；
- 关键证据摘要；
- `unknown` 或 `uncertain_transition` 状态；
- 用户是否回应。

具体字段和 prompt 必须在分类输出稳定后确定，MiMo 不接收可辨认原始画面。

## 8. 决策标准

- **Go**：骨骼连续，站/坐/躺/未知可稳定分类；至少一个标注跌倒式转变能与正常转变区分。
- **Conditional Go**：静态姿态可靠，但跌倒式转变不可靠；保留姿态监测与 MiMo 询问，不宣称跌倒检测。
- **No-Go**：骨骼提取不连续，或站/坐/躺仍大面积混淆；更换视频、机位或姿态提取器。
