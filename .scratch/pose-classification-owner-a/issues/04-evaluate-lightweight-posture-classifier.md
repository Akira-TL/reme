# 04 — 评估轻量姿态学习模型

**Type:** task

**What to build:** 在与几何基线相同的数据划分和标签体系上，评估至少一种轻量学习模型，判断它是否在稳定性、拒判能力或姿态区分上带来真实收益。数据不足时，本票应产出明确的停止结论，而不是强行训练。

**Blocked by:** 02 — 标注姿态与转变并评估样本覆盖。

**Status:** ready-for-agent

- [ ] 在训练前检查各类别、人物和场景的样本量；不满足最低覆盖时输出 no-go 或补拍要求，不报告无意义准确率。
- [ ] 使用与几何基线完全相同的 train、val、test 划分和关键点归一化约定。
- [ ] 至少评估一个简单学习基线，并在数据量允许时评估现有 Conv1D 候选；模型窗口和步长必须记录。
- [ ] 置信度阈值和 `unknown` 拒判策略只在验证集校准。
- [ ] 推理输出符合共享接口中的 `PostureObservation`，低质量输入能够显式拒判。
- [ ] 报告每类 precision、recall、F1、macro-F1、混淆矩阵、拒判率、标签抖动和推理性能。
- [ ] 与 Ticket 03 的几何基线在同一报告中比较，并按证据说明学习模型是否值得进入比赛路径。
- [ ] 保存可重复加载的模型、配置、类别映射和预处理说明，并提供训练、评估、推理的固定命令。
- [ ] 为数据窗口生成、标签对齐、模型加载和输出合同提供自动化测试或烟雾测试。
