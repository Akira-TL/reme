# 06 — 评审证据并冻结 A 的比赛能力

**Type:** task

**What to build:** 汇总静态姿态、轻量学习模型和时序事件的测量证据，作出 Go、Conditional Go 或 No-Go 决策，并冻结比赛演示真正支持的标签、模型、阈值、拒判策略和对外表述。

**Blocked by:** 03 — 建立静态姿态几何基线；04 — 评估轻量姿态学习模型；05 — 建立静止与动作转变事件基线。

**Status:** ready-for-agent

- [ ] 使用同一测试集和统一指标汇总 Ticket 03、04、05 的结果，不选择性隐藏失败类别或误报场景。
- [ ] 明确静态姿态最终采用几何基线、学习模型还是组合方式，并记录选择依据。
- [ ] 明确跌倒式转变是自动识别、条件展示、脚本触发还是完全不展示，并给出证据依据。
- [ ] 冻结比赛支持的姿态标签、转变标签、质量状态、采样频率、窗口参数、阈值和拒判规则。
- [ ] 确认 A 的输出严格符合 `accepted-for-demo` 的 A/B/C 共享接口；如需变更接口，先完成跨角色评审和版本更新。
- [ ] 输出 Go / Conditional Go / No-Go 结论，列出可对外宣称、必须限定表述和禁止宣称的能力。
- [ ] 记录已知限制，包括人物、机位、环境、遮挡、数据量、泛化和非医疗用途边界。
- [ ] 更新 A 工作规格、实验报告和交接说明，使 B、C、D 使用同一事实基线。
- [ ] 冻结后只允许修复 P0 缺陷；新增类别、更换模型或调整核心阈值必须重新经过证据评审。
