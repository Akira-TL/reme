# 07 — 生成离线交付包并完成 ABC 联合验收

**Type:** task

**What to build:** 为比赛冻结场景生成 A 的最终离线数据包，并与 B、C 完成一次真实接口验收。完成后，即使现场不重新运行姿态模型，B 仍能读取姿态与转变进行推理，C 仍能同步回放视频、骨架、姿态和事件。

**Blocked by:** 06 — 评审证据并冻结 A 的比赛能力。

**Status:** ready-for-agent

- [ ] 每个冻结场景均包含可解析的 `SceneManifest`、2D 关键点流、姿态观察流、转变事件流和可选 3D 关键点流。
- [ ] manifest 中的所有本地引用可在干净环境下解析，文件哈希、帧率、时长、坐标空间、模型配置和 schema 版本完整。
- [ ] B 能仅通过共享接口读取姿态观察、转变事件和受控媒体引用，不需要访问 A 的模型内部状态。
- [ ] C 能通过 manifest 同步播放视频、骨架、姿态、置信度、质量状态和事件时间线，不需要猜测字段含义。
- [ ] `unknown`、`uncertain_transition`、人体未检出和数据不可用状态在 B/C 侧均能显式显示或降级处理。
- [ ] 提供一条命令从冻结输入生成完整数据包，并提供无需模型运行的纯离线回放方式。
- [ ] 同一场景连续执行至少三次，输出文件结构、字段、事件顺序和时间同步不发生漂移。
- [ ] 完成 A→B→C 最小回放验收记录，列出发现的问题、修复状态和仍需接受的限制。
- [ ] 输出最终交接说明，包含目录结构、运行命令、字段版本、已知限制、失败恢复和比赛现场使用方式。
