# 03 — 建立静态姿态几何基线

**Type:** task

**What to build:** 使用归一化人体关键点建立可解释的静态姿态分类基线，并端到端输出共享接口定义的姿态观察。该基线既用于验证标签是否可分，也作为后续学习模型的比较对象和比赛失败时的可解释降级方案。

**Blocked by:** 02 — 标注姿态与转变并评估样本覆盖。

**Status:** ready-for-agent

- [ ] 从 17 点骨架提取对平移和尺度稳定的特征，至少覆盖躯干方向、关节角度、人体中心高度、包围盒比例、运动程度和可见关键点比例。
- [ ] 几何规则和阈值只使用 train/val 数据确定，测试集不得参与调参。
- [ ] 关键点质量不足、人体未检出或特征冲突时能够输出 `unknown` 和明确的 `landmark_quality`，不得沿用上一帧标签伪装成功。
- [ ] 推理结果使用共享接口中的 `PostureObservation` 字段、枚举和时间单位，并保持时间戳有序。
- [ ] 在固定测试集上报告每类 precision、recall、F1、macro-F1、混淆矩阵和拒判率。
- [ ] 记录标签抖动次数、错误发生的场景与时间范围，并可以回放对应骨架片段。
- [ ] 为确定性特征计算、阈值判断、持续时间累计和拒判行为提供自动化测试。
- [ ] 提供固定命令生成预测和评估报告，同一输入重复运行不会发生 schema 或标签漂移。
