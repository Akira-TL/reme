# 05 — 建立静止与动作转变事件基线

**Type:** task

**What to build:** 基于连续关键点和姿态观察识别持续静止、正常转变、跌倒式转变与不确定转变，输出客观事件事实供 B 推理和 C 展示。该模块不得把静止或躺卧直接解释为危险。

**Blocked by:** 02 — 标注姿态与转变并评估样本覆盖。

**Status:** ready-for-agent

- [ ] 使用明确的时间窗口计算人体中心高度变化、躯干方向变化、关键点速度、转变前后姿态和关键点质量。
- [ ] 分开输出 `normal_transition`、`fall_like_transition` 和 `uncertain_transition`，不得使用单帧规则代替时序判断。
- [ ] 持续静止通过 `posture_duration_ms` 和 `motion_level` 表达，不在 A 端输出报警、通知家属或风险等级。
- [ ] 事件输出符合共享接口中的 `TransitionEvent`，包含起止时间、置信度、客观证据和质量状态。
- [ ] 正常坐下、正常躺下、弯腰/下蹲和跌倒式转变在评估中分别记录，不将正常动作误报隐藏在总体准确率中。
- [ ] 报告每类事件检出情况、正常转变误报数、事件检测延迟、`uncertain_transition` 比例和错误时间段。
- [ ] 关键点缺失、镜头切换、动作边界不足或证据冲突时能够输出不确定事件。
- [ ] 为时间窗口、持续时间、事件合并、事件去重和质量降级提供确定性自动化测试。
- [ ] 提供固定命令生成事件文件和评估报告，同一输入重复运行保持事件顺序与 schema 稳定。
