- 没有检测到关键点接近图像边缘的离画候选帧。

### 抖动候选

本次巡检使用“相邻帧各关键点位移的中位数”，只用于找出需要观看的时间点：

- 全视频位移中位数：`0.002910`；
- 位移 P95：`0.013084`；
- 优先回放窗口：
  - 17.8–18.4 秒；

  - 65.8–66.7 秒；

这些峰值可能来自真实快速动作，也可能来自关键点抖动，必须通过视频回放区分。

## 7. 完整复现命令

```bash
mkdir -p models/movenet
wget -O models/movenet/movenet_lightning_f16_v4.tflite \
  'https://tfhub.dev/google/lite-model/movenet/singlepose/lightning/tflite/float16/4?lite-format=tflite'
sha256sum models/movenet/movenet_lightning_f16_v4.tflite
```

期望 SHA-256：

```text
0fac2226112d0371903ca86e3853cec24ef603a0b2f96f589b180f0ebdd135ab
```

### 7.2 重建 MoveNet 原始派生结果

```bash
.venv/bin/python .scratch/litert-movenet-feasibility/run.py \
  --model models/movenet/movenet_lightning_f16_v4.tflite \
  --video 148703662.mp4 \
  --output-dir artifacts/pose-classification/extractions/video_148703662 \
  --score-threshold 0.2 \
  --num-threads 4 \
  --tracking-crop
```

### 7.3 构建共享接口场景包

```bash
PYTHONPATH=backend .venv/bin/python -m reme.scene_bundle package \
  --scene-id video_148703662 \
  --title '目标视频 148703662' \
  --video 148703662.mp4 \
  --legacy-keypoints artifacts/pose-classification/extractions/video_148703662/keypoints.jsonl \
  --skeleton-video artifacts/pose-classification/extractions/video_148703662/skeleton.mp4 \
  --run-summary artifacts/pose-classification/extractions/video_148703662/summary.json \
  --output-dir artifacts/pose-classification/scenes/video_148703662
```

### 7.4 校验场景包


## 8. 隐私与证据边界

- MoveNet 默认运行不输出逐帧原始图片；
- 本场景包保留用户提供的源视频副本、关键点、骨架视频和摘要；
- 不生成额外解码帧目录；
- 摘要记录 `raw_frames_written = false`、`raw_frames_uploaded = false`；
- 源视频只在本地场景包中使用；B 是否向 MiMo 发送最小视觉上下文由 ADR-0003 和 B 的请求记录控制。

必须继续区分：
