# LBX 与主分支视觉对齐计划

## 目标

仅在 `lbx` 分支把双端演示的视觉语言对齐 `upstream/main`，保留 LBX 已有的实时骨架、四场景、授权视频、唯一控制租约与 fail-closed 隐私逻辑。

## 视觉基准

- 基准提交：`upstream/main@a4e86259`
- 参考页面：主分支 `home-normal.png`、`home-cooking.png`、`home-risk.png`、`home-emergency.png` 与 `settings.png`
- 主色：橙色 `#ff5a00`
- 正常：绿色 `#239a34`
- 告警：红色 `#ff3b30`
- 表面：白色、暖灰 `#ecebea`、轻橙 `#fff0e5`
- 字体：系统字体 / SF Pro / PingFang SC
- 形态：手机优先、充足留白、圆角卡片、轻边框与柔和阴影

## 当前差异

- LBX 当前使用深绿/深棕控制室主题和青色骨架，与主分支不一致。
- 评委端是“舞台 + 说明侧栏”的桌面展陈结构，移动端缺少主分支的看护首页感。
- 场景环境由 CSS 几何图形拼接，既不贴近主分支，也容易产生不自然的剪切感。
- 解锁页与监控页采用不同于主分支的暗色终端风格。

## 实施范围

1. 评委端改为白色看护首页语言：暖色场景画面、橙色骨架、绿色正常卡、红色告警卡、白色时间线/信息卡。
2. 日常/跌倒前与厨房使用项目已有的固定通用场景图片，不宣称家具识别或现场复原。
3. 浴室继续纯骨架与中性安全背景，不显示环境图片；跌倒升级后仍由现有授权链路切换真实视频。
4. 监控端、密钥解锁页统一为白色/暖灰/橙色表单和控制面板，保留手机优先布局。
5. 使用现有 MUI 图标，移除可见的 CSS 家具与符号占位图。

## 不变边界

- 不修改 `upstream/main`，不处理 fork/origin。
- 不改变中继协议、媒体授权、模型推理、跌倒规则或活动识别语义。
- 不新增云端原始视频存储，不把固定场景图描述为现场重建。
- 所有降级、无人物、媒体不可用和授权状态继续明确显示。

## 验证

- 同一 `390 × 844` 视口对照主分支参考与 LBX 实现。
- 检查评委端等待态、日常、厨房、浴室、跌倒/告警视觉状态。
- 检查监控端锁定态和解锁后移动端布局。
- 运行 `npm test`、`npm run lint`、`npm run build`。
- 只提交并推送 `upstream/lbx`，部署后验证 `reme.maniforld.com` 与 `monitor.reme.maniforld.com`。
