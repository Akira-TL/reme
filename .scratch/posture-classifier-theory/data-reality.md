# 可用真实数据的实测事实（分类器设计的硬约束）

- 日期：2026-08-01
- 数据：`examples/keypoints/movenet17-v0-experiment.jsonl`（取自分支 `adr-0003-keypoint-frame-record`，
  已复制到 `.scratch/posture-classifier-theory/data/movenet17-real-2370.jsonl`）
- 来源视频：`148703662.mp4`，1280×720，30 FPS，2370 帧，78.97 秒，单人
- 提取器：MoveNet SinglePose Lightning FP16 + 逐帧跟踪裁剪

本文件记录的是**实测数字**，不是推测。所有数字可用
`.scratch/posture-classifier-theory/data/` 下的 JSONL 复算。

## 1. 结论摘要

1. **唯一的真实人体素材（79 秒 2370 帧）只有一种静态姿态：`standing`。**
   没有 sitting、没有 lying、没有 bending_or_crouching、没有任何跌倒式转变。
2. 仓库另有一份覆盖全部 5 个标签的目录 `downloads6-animation-bootstrap-v2`（23 个片段），
   但它是**动画参考素材**、标签由**文件名推断**、媒体文件**当前不在本机**（见第 1.1 节）。
   它不能替代真实人体数据。
3. 因此**任何需要多类别真值的学习型分类器，在当前数据上无法训练、无法验证**。
   这直接命中 A 规格验收清单里"样本不足时必须记录 no-go 和最小补拍要求，不强行训练"这一条。

### 1.1 `downloads6-animation-bootstrap-v2` 的真实性质

来源：`.scratch/pose-classification-owner-a/datasets/downloads6-catalog.json`

| 属性 | 值 |
|---|---|
| `label_source` | `filename_inference`（按文件名推断标签，非人工逐段标注） |
| `evidence_level` | `weak_label_bootstrap` |
| `root` | `artifacts/pose-classification/raw/downloads6` —— **本机不存在该目录** |
| 片段数 | 23 |
| 标签分布 | sitting 7、bending_or_crouching 5、unknown 5、standing 4、lying **2** |
| 划分 | train 13 / val 4 / test 6；**lying 的 test 只有 1 个片段** |

素材本身是 3D 动画动作参考（文件名含"Animation reference by 3D2M动…"，
以及"剑士坐姿""公主礼""女孩子般的坐下"等风格化动作）。三个独立问题：

- **人体测量学失配**：动画角色的头身比、四肢长度比例是风格化的，
  与 Dempster / Winter 等基于真实成人的环节参数不一致。用真人先验去校准动画数据，
  或反过来用动画数据去验证真人先验，两个方向都不成立。
- **目标人群失配**：产品面向独居老人。老年人的躯干几何（脊柱后凸、身高丢失）
  与年轻成人已有差异，与动画角色差异更大。
- **标签强度不足**：文件名推断 + 每类 1 个测试片段，得到的任何 precision/recall
  都只是轶事，不能作为项目指标对外报告。

结论：这份目录可以用作**冒烟测试与流水线连通性验证**，
**不能**用作分类器的训练真值或验收依据。
3. 受试者在大部分时间里**接近侧向（矢状面）面对相机**，双肩在图像上几乎重合。
   这既是风险（左右判别不可靠），也是机会（矢状面角度恰好是躯干/髋/膝屈伸的测量平面）。
4. 关键点连续性很好：2370/2370 帧 `torso_detected=true`，躯干/髋/膝/踝的
   `score >= 0.2` 覆盖率为 100%；四肢末端（腕、肘）有 2.4–4.5% 的低置信帧。
5. 由 1–2 推出本次设计的路线：**以理论先验定参的可解释几何分类器**，而不是数据驱动模型。
   参数来自人体测量学与临床文献，验证靠（a）几何精确构造的合成用例，
   （b）真实片段上的 `standing` 稳定性与零抖动，（c）对其余类别诚实标注"未经本项目数据验证"。

## 2. 姿态量的全序列统计（像素空间，已按 1280×720 还原纵横比）

以左右中点定义躯干/大腿/小腿段。角度单位为度。

| 量 | min | p5 | p50 | p95 | p99 | max |
|---|---|---|---|---|---|---|
| 躯干与图像竖直方向夹角 | 0.0 | — | 3.7 | 9.0 | 10.8 | 13.7 |
| 大腿段与水平方向夹角 | 73.7 | 81.4 | 86.0 | — | — | 90.0 |
| 小腿段与水平方向夹角 | — | 77.4 | 82.0 | — | — | — |

- 躯干**从未**超过竖直方向 15°（超过 15° 的帧数：0）。
- 大腿段**始终**接近竖直（与水平夹角最小 73.7°）。临床久坐行为研究用于区分
  sit/stand 的大腿倾角判据在这段数据里全程落在 standing 一侧，没有任何越界样本。
- 髋 < 膝 < 踝 的竖直序关系在 **100%** 帧成立（0 个反例）。

高度稳定性（像素）：

| 量 | min | max | std |
|---|---|---|---|
| 髋中点 y | 398.1 | 442.4 | 8.4 |
| 踝中点 y | 580.4 | 635.5 | 11.6 |
| 头顶(鼻)到踝的竖直跨度 | — | — | 16.7（均值 318.9）|

髋高在 79 秒内总变化 44 px（约人体像素身高的 14%），不存在坐下/躺下所需的

腕 `y` 的 std 为 0.119–0.120（归一化单位），躯干与下肢的 std 均在 0.010–0.018。
即：**这是一个站立不动、只活动手臂的人。**

## 4. 视角实测：受试者接近侧向

以像素计的肩宽与躯干长度之比：

- 观测中位数 `biacromial_px / torso_px = 0.12`
- 人体测量学期望（Winter 教材的环节比例，正面视角）：肩宽 ≈ 0.245×身高，
  躯干（肩峰到髋关节）≈ 0.288×身高，故期望比值 ≈ **0.85**

观测值仅为期望的 **1/7**，说明双肩连线几乎与相机光轴平行——受试者大体上是**侧向（矢状面朝向相机）**。
个别帧（例如 frame 1200）该比值回升到 0.74，说明期间有转身。

这对设计有两个直接后果：

1. **左右判别不可靠。** 侧向时左右同名关节在图像上重合，任何依赖左右差异的特征
   （左右不对称性、单侧支撑判断）在这段数据上必须降权或拒判。
2. **矢状面角度反而可信。** 躯干前屈/后伸、髋屈、膝屈都是矢状面运动；相机接近正对矢状面时，
   图像上量到的角度接近真实解剖角度。反过来，当受试者正面朝向相机时，同样的屈曲会被
   投影压缩，图像角度会**系统性低估**真实屈曲角。

因此设计必须包含一个**视角/前缩（foreshortening）估计量**：用实测
`biacromial_px / torso_px` 与人体测量学期望的比值，反推躯干朝向相机的角度，
并据此调整置信度或触发拒判。这是把"透视会扭曲角度"这一物理事实变成可运行代码的关键接口。

可见点比例自行推导，而不是假定 `usable`）。

## 6. 实测误差预算（置信度模型的经验基础）

置信度不能凭空写。下面的 σ 是从**这段真实数据本身**估计出来的，可复算。

### 6.1 估计方法

对每个关键点的坐标序列取二阶差分 `d2[t] = p[t+1] - 2p[t] + p[t-1]`。
若信号 = 局部近似线性的真实运动 + 独立同分布定位噪声 σ，则 `std(d2) ≈ σ√6`。
为了把真实的快速运动当作离群值剔除，用 MAD 稳健估计代替标准差：
`σ̂ = 1.4826 × MAD(d2) / √6`。

（先用"9 帧滑动平均残差"估计得到 σ≈7 px，但那个数把**真实的身体摆动**也算成了噪声，
是上界而非噪声本身。下表的 MAD 估计才是可用的定位噪声。两者的差距本身说明：
在这段素材里，躯干与下肢的低频运动幅度远大于定位噪声。）

### 6.2 结果（像素，@1280×720）

| 关节 | σx | σy |
|---|---|---|
| 双髋 | 0.83–0.98 | 1.01–1.12 |
| 双肩 | 1.28–1.32 | 1.41–1.47 |
| 双膝 | 1.09–1.12 | 1.60–1.73 |
| 双踝 | 1.14–1.16 | 1.25–1.35 |
| 头部五点 | 1.11–1.29 | 1.02–1.48 |
| 双肘 | 1.95–1.96 | 2.08–2.13 |
| 双腕 | 2.00–2.09 | 2.09–2.36 |

核心 8 点（肩/髋/膝/踝）各向同性 σ：**中位数 1.31 px**，最大 1.45 px。
归一化单位约 **0.001–0.002**。

**重要限制**：该估计只能捕捉逐帧独立的抖动，**捕捉不到系统性偏差**
（例如 MoveNet 把髋关节中心一贯地估偏几个像素）。系统偏差需要 3D 真值才能测，本项目没有。
因此下面推出的角度不确定度是**下界**，不是全部误差。

### 6.3 传播到关节角

两点段的角度不确定度近似 `δθ ≈ √2·σ / L`（弧度，L 为段的像素长度）：

| 段 | 实测 L (p50) | 1-σ 角度不确定度 |
|---|---|---|
| 躯干（肩中点–髋中点） | 101.5 px | 1.04° |
| 大腿（髋–膝） | 100.4 px | 1.06° |
| 小腿（膝–踝） | 89.9 px | 1.18° |
| 假想 40 px 段 | 40 px | 2.65° |
| 假想 20 px 段 | 20 px | 5.30° |

由此得到两条**可直接编码的拒判规则**：

- 要让某段角度的 1-σ 优于 5°，该段像素长度必须 **≥ 21 px**；
- 要优于 10°，必须 **≥ 11 px**。

段长低于阈值时，该段派生的角度证据必须降权或直接拒判——这是"为什么置信度是这个值"
可以被核查的物理依据，而不是拍脑袋的数字。

### 6.4 score 不是精度的代理

实测 `corr(关节平均 score, 关节抖动幅度) = -0.31`——只有弱负相关。
MoveNet 的 `score` **不是标定过的定位精度**，不能直接当作 `1-σ` 或概率使用。
它只能作为"该点是否可用"的粗筛（阈值化），不能作为置信度的连续权重。

### 6.5 骨长比例自洽性（实测基线）

小腿/大腿像素长度比：实测 89.9 / 100.4 = **0.90**。
Winter 教材的环节比例给出的期望约为 1.00（大腿 ≈ 0.245×身高，小腿 ≈ 0.246×身高）。
观测值略小于 1，与"受试者略有前缩"一致。这说明骨长比例检验可以作为几何自洽性检查使用，
其正常波动带需要按上面的 σ 与实测分布共同确定，不能直接把 1.00 当硬性期望。

## 6.6 与文献误差预算的对账（实测 σ 代入）

`notes/measurement-error.md` 的误差预算以 `σ_p = 0.02·H`（H = 人体在画面中的像素高度）
为现实量级假设。本项目**实测**为：σ ≈ 1.31 px，H（鼻→踝）≈ 318.9 px，故

```
σ_p / H = 1.31 / 318.9 ≈ 0.0041·H      （约为文献假设的 1/4.9）
```

把实测值代入该笔记的公式，得到本项目的**真实**误差预算：

| 量 | 笔记假设 σ_p=0.02H | 本项目实测 σ_p=0.0041H | 是否可用 |
|---|---|---|---|
| 躯干倾角（两点向量） | 5.6° | **1.15°**（与本文 §6.3 独立算得的 1.04° 相符） | 可用 |
| 膝角（三点） | 11.4° | **2.34°** | 可用 |
| 肘角（三点） | 17.2° | **3.5°** | 勉强，仍是最差项 |
| 速度（中心差分） | 0.42 H/s | **0.086 H/s** | 可用但不推荐 |
| 速度（Savitzky–Golay w=9,p=2） | 0.077 H/s | **0.016 H/s** | 推荐 |
| 加速度（二阶导） | 44 H/s² | **9.0 H/s²** | **仍不可用** |

三条结论：

1. **本项目的噪声比文献假设好约 5 倍**，因此躯干/膝/髋角度是可用的，
   笔记中"肘腕角在任何尺度下都不可用"的结论在本项目条件下可放宽为"最差但非不可用"。
   实现时必须用**实测 σ**驱动置信度，不能沿用笔记的悲观假设。
2. **"禁止使用二阶导（加速度）特征"这一条即使用实测 σ 也依然成立**：
   σ_a = 9.0 H/s² 仍大于 1.7 m 人体上的重力尺度 5.8 H/s²（噪声约为信号的 1.55 倍）。
   这条禁令是稳健的，不随噪声估计的乐观/悲观而改变，应写进设计硬约束。
3. 求导必须**先滤后导**。中心差分把白噪声放大 `fs/√2 = 21.2/s`（30 FPS）；
   SG(w=9,p=2) 导数核把噪声增益从 0.707 降到 0.129，约 5.5 倍改善。

### 6.7 用主轴代替两点向量（精度提升 4.7 倍）

`notes/measurement-error.md` 给出：可靠关键点云的**加权主轴角**精度为

```
σ_axis = σ_p / sqrt( Σ_k (t_k − t̄)² )
```

其中 `t_k` 为点在主轴上的投影坐标。站立构型下，9 个核心点（鼻 + 双肩 + 双髋 + 双膝 + 双踝）
的 `Σ(t−t̄)² = 0.906·H²`，因此主轴角精度比"肩中点→髋中点"两点向量高约 **4.7 倍**。

代价与约束：四肢构型会**系统性**带偏主轴（那是信号不是噪声），
因此必须限定在核心点子集上计算，并使用逆方差加权。
设计应当把主轴角作为躯干朝向的主估计量，两点躯干向量退居为一致性交叉校验。

## 7. 对验收的影响

在补拍包含坐/躺/弯腰/跌倒的视频之前，可以诚实主张的只有：

- 分类器在真实素材上对 `standing` 的稳定性、抖动次数、拒判率；
- 分类器在**几何精确构造的合成用例**上对各类判据的正确性；
- 分类器的判据、阈值与出处可被逐条核查。

不可主张的：任意类别的 precision/recall/F1、跨人物泛化、跌倒检测能力。
报告里必须写明"其余类别的阈值来自文献先验，尚未在本项目数据上验证"。
