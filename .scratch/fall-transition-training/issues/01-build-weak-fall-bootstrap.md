# 01 — 建立跌倒视频弱监督数据准备链路

**Type:** task

**Status:** claimed

**What to build:** 从根目录无标记/带标记的同源跌倒合集建立50段候选片段，提取无标记视频的MoveNet关键点，并生成可审计的standing/fallen锚点与跌倒候选窗口。不得在无人工复核测试边界时报告真实跌倒准确率。

**Blocked by:** none

- [x] 校验两份视频时长基本一致，并记录各自分辨率、帧率和哈希。
- [x] 在无标记视频上检测49个候选场景边界，形成50个片段。
- [x] 边界选择具有确定性、最小间距和自动化测试。
- [x] 片段级train/val/test划分固定，marked/raw同源内容不得跨split。
- [ ] 只对无标记视频提取MoveNet关键点，原始帧不落盘。
- [ ] 每段寻找稳定standing锚点、稳定低位/lying锚点和最小转变窗口。
- [x] 无可靠锚点或质量不足时输出uncertain/rejected，不强制生成正样本。
- [ ] 输出机器可读候选报告和人工复核清单。
- [x] 标记版只作为审核媒体引用，不作为训练像素输入或自动真值。
- [x] 记录需要补充的正常躺下、坐下、弯腰/下蹲等硬负样本。
- [x] Pytest、Ruff、Mypy strict、uv build和git diff --check通过。

## Comments

2026-08-02：原视频约232.958秒、960×544@24 FPS；标记版约232.982秒、1280×720@23.976 FPS。低阈值场景差异检测得到约49个明显边界，与50个片段一致，但边界与事件时间仍需骨架证据校正。标记版红色覆盖出现区间多于50段，不可直接作为机器真值。
