# Reme 家中端按钮与层级重构规格

- Status: accepted-for-local-implementation
- Date: 2026-08-09
- Base: `d6b1e4c6`
- Branch: `codex/home-surface-refine`
- Scope: `/home` presentation only; `/debug` capability surface must remain unchanged
- Cloud gate: closed

## 1. 目标

家中端不是工程控制台。未启动时只回答一个问题：是否开始关怀；运行后才展示与当前媒体、连接、问询和故障直接相关的控制。保留全部真实 A/B、MiMo、Relay、媒体、告警和隐私能力，不新增按钮、路由、模拟状态或产品实体。

## 2. 基线“查”

390×844 未启动首屏实测：

| 控件 | 状态 | 面积 | 占全部 button 面积 | 占首屏面积 | 目的 |
|---|---|---:|---:|---:|---|
| 进入全屏 | 可用，中性白 | 1,936 px² | 6.08% | 0.59% | 工程/展示辅助，不是老人主任务 |
| 开始关怀 | 可用，橙色实心 | 14,960 px² | 46.96% | 4.54% | 请求本机权限并启动真实关怀会话 |
| 前后切换 | 禁用，中性灰 | 14,960 px² | 46.96% | 4.54% | 仅摄像头运行后切换朝向 |

另有一个禁用的媒体源 combobox。严格按 `<button>` 计为 3 个、其中 2 个可用；把 combobox 计入交互控件则为 4 个，橙色控件数量 25%、中性/禁用 75%。当前核心问题是禁用工具与主动作等宽等高，而非按钮总数过多。

源码还有停止、重试、收回 controller、问询三键和 Debug 本机确认按钮，但它们按状态互斥。Home 远程命令只允许 `confirm_alarm`，因此“本机权限确认”队列在 Home 不可达，不应常驻。

## 3. 增删改换裁决

### 改

- 未启动 Home 只显示一个橙色“开始关怀”按钮。
- 运行后才显示媒体选择、连接事实和停止动作；摄像头工具仅在摄像头真实启用时出现。
- `停止演示` 改为 `停止关怀`；媒体选择改为面向用户的“选择相机或视频”。
- 移除 Home 中 `generation`、`prompt` 等工程口径，错误本身仍必须如实显示。
- 移动端运行态把老人当前关怀问题排在实时画面之前。
- 问询的“再听一遍”降为紧凑次级动作；安全询问中只有“我需要帮助”使用危险红，“我没事”使用中性描边；同意询问中只有“同意分享”使用品牌橙。

### 换

- Home 的开始按钮从 MUI warning 橙换成既有品牌橙 `#ff5a00`，不引入新强调色。
- 启动前警告三角换为隐私图标，文案缩短，但继续明确无账号验证、相机/麦克风、MiMo 视觉/语音外发以及全部在线 Viewer 的限时原画受众。
- 只读状态与按钮视觉分离：状态不使用按钮式描边和悬浮感。

### 删

- Home 删除全屏按钮；Debug 保留。
- Home 未启动时隐藏媒体源选择、摄像头切换、公开连接空状态和大面积实时画面占位。
- Home 删除不可达的本机确认空队列及确认/拒绝按钮；Debug 保留完整队列。
- Home 顶栏删除重复的媒体/模型状态，只在运行后保留一个总关怀链路状态；详细故障仍在真实画面与控制区显示。
- Home 不显示非摄像头状态下的禁用摄像头切换按钮。

### 增

- **不增加任何可见实体、按钮、能力、路由、数据或模拟状态。**
- 仅允许为现有实体增加表意 class、条件渲染和确定性测试。

## 4. 目标按钮状态

| Home 状态 | 可见按钮 |
|---|---|
| 未启动 | 开始关怀（1） |
| 运行中、无事件 | 停止关怀；真实错误时可见重试；controller 活跃时可见收回 |
| 安全询问 | 再听一遍、我没事、我需要帮助（3） |
| 分享同意 | 再听一遍、同意分享、这次不分享（3） |
| Debug | 保持现有完整工程按钮，不受本规格删减 |

媒体源 Select 不计为按钮；它只在 Home 已启动时显示。摄像头朝向通过媒体源选择完成，不再额外保留 Home 的“前后切换”按钮。

## 5. 颜色原则

- 未启动 Home 的可见 button 面积为品牌橙 100%，因为只有一个主动作。
- 日常运行不使用红色；红色只给真实“我需要帮助”或权威危险状态。
- 绿色只用于已确认成功，不用于“看起来正常”的推断。
- 暖白/中性色承担 85–90% 页面面积；橙色只承担主动作与品牌；蓝色隐私披露降低面积与饱和度，不与 CTA 争夺视觉中心。

## 6. 不变量

- 不改 A/B、MiMo、Relay、WebRTC、媒体权限、事件、倒计时、告警或隐私策略。
- 不允许 synthetic fallback、Debug scenario 或远程媒体命令进入 Home。
- Home 仍须在采集前披露 ADR-0003 与 ADR-0008 的真实边界。
- 相机拒绝、后端离线、无关键点、MiMo 视觉提交失败等状态继续 fail-visible。

## 7. 验收

- 390×844 未启动：仅 1 个可见 button；CTA 在首屏；无横向滚动；无假手机边框。
- 320、390、430、768、1440 宽度：布局不溢出；关键按钮至少 44×44。
- Home 未启动不渲染实时画面/问询空占位；启动后真实失败仍可见。
- Home 无全屏、前后切换、确认/拒绝、Debug/场景/重置按钮。
- Debug 的全屏、媒体、本机确认、场景和工程控制保持不变。
- `npm test`、`npm run lint`、`npm run build`、`npm run test:route-build` 全部通过。
- 使用相同 390×844 与 1440×900 视口制作前后对比并复核。

## 8. 本地实现结果

- 390×844 未启动态实测只剩 `开始关怀` 1 个 button、0 个 combobox；按钮为 `#ff5a00`，面积 17,264 px²，占全部可见 button 面积 100%、占首屏面积 5.24%。
- 相比基线，button 数量从 3 降到 1（减少 66.7%）；把 combobox 算入控件时从 4 降到 1（减少 75%）。
- 320、390、430、768 与 1440 宽度均无横向溢出；开始按钮高度 52px。
- Home 未启动不再渲染实时画面、问询空状态、媒体选择、摄像头切换或本机确认队列。
- Debug 仍保留全屏、四场景、媒体源、摄像头切换、本机确认队列与工程验收面。
- 本地验证通过：`npm test` 133/133、`npm run lint`、`npm run build`、`npm run test:route-build` 4/4。
- 同视口对比证据：`evidence/05-home-before-after-390x844.png`；未改变任何云端状态。
