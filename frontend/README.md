# Reme 手机端交互 Demo

这是按照 7 张高保真视图制作的手机端 HTML 原型。页面以原始设计稿作为视觉底层，再叠加可点击热点、iOS 弹层、场景切换与本地姿态识别，因此页面结构和图标可以保持一致。

## 启动

双击 `启动Reme手机演示.command`，浏览器会自动打开：

```text
http://127.0.0.1:4174
```

首次打开时允许浏览器使用摄像头。摄像头原画不会在页面中显示，只用于本机姿态推理；检测到单人后显示 17 节点橙色火柴人。

首次姿态模型初始化需要联网加载 MediaPipe 模型。如果模型无法访问，页面会自动切换到动态演示姿态，其他交互不受影响。

## 可交互内容

- 首页标题：切换客厅实时、做饭、洗澡隐私、异常姿态四类场景。
- 右上角设备按钮：在产品视觉稿和真实摄像头火柴人层之间切换。
- 风险场景：约 0.9 秒后触发紧急弹窗，可模拟呼叫、查看实时状态、联系紧急联系人。
- 看板页：点击本周摘要、做饭、对话、情绪曲线、心路历程查看详情。
- 设置页：自动隐私保护与 MiMo 主动关怀支持开关，其他设置项会打开详情弹层。
- 底部导航：首页、看板、设置三页可切换。

## 手机查看

同一 Wi-Fi 下，可以把启动脚本终端中显示的本机局域网地址替换进手机浏览器。iPhone 对摄像头权限通常要求 HTTPS；用于比赛现场时，建议直接在 Mac 浏览器中用手机比例演示，或部署到 HTTPS 地址。
