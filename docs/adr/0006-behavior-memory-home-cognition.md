# ADR-0006: 行为语义 · 长期记忆 · 全屋上下文——B 认知增强层的学科依据与边界

- 状态：Accepted（B 域内部决策，不改变 A/B/C 合同任何字段）
- 日期：2026-08-01
- 关联：ADR-0002（衍生运动数据为核心）、ADR-0003（最小视觉上下文）、ADR-0005（先问候、确定性升级、模型不可撤销）

## 背景

B 收到的是 A 的去标识粗粒度流（PostureObservation / TransitionEvent），却要回答一个更高阶的问题：**这个人此刻的行为意味着什么、他想做什么、系统该不该主动介入**——即"基于人物行为与空间变动判断人物目的"的空间智能。约束：

1. 合同冻结，不给 A/C 增加任何义务；
2. 单目未标定摄像头，无深度、无绝对尺度；
3. 隐私优先：原始画面不出户（ADR-0001），B 只碰衍生数据；
4. MiMo 是认知中枢，但升级决定权归确定性规则（ADR-0005）。

## 决策

在 B 内部加三层**确定性**认知上下文，全部注入 MiMo 提示词，并在硬安全界内调制触发阈值：

| 层 | 模块 | 内容 |
|---|---|---|
| 行为语义 | `decision/behavior.py` | 回看窗口的时序特征：体位变化率、静止片段、坐↔站/躺↔起转换、主导体位、跌倒/不确定转换计数；空间线索（下坠时长、质心下降比、落地后残余运动）作为 `TransitionEvent.evidence` 的**休眠超集**解析——有则用，无则零影响 |
| 长期记忆 | `decision/memory.py` | 分时段（0-23 时桶）活动基线 EWMA、里程碑事件史（主诉/跌倒/授权/化解）、今日相对基线的偏离度；持久化 JSON，跨会话累积 |
| 全屋上下文 | `decision/home.py` | 房间语义 × 时刻 × 环境信号（通用抽象，非任何厂商协议）：同一体位在不同上下文含义翻转——凌晨卧室躺=睡觉（阈值放宽 3 倍），卫生间躺=需要问候（阈值减半且 LYING 进入关注体位） |

### 安全不变量（继承并扩展 ADR-0005）

1. 三层只**添加上下文、收紧注意力**；任何一层都不得放松跌倒规则：`fall_confidence_min`、超时、rewind、隐私档位在上下文调制中原样拷贝，静止阈值缩放钳制在 [0.5, 3.0]。
2. 记忆与上下文只进提示词与阈值调制，**不进状态机转移条件**——升级台阶仍由规则独占，MiMo 与记忆都撤销不了已有告警（risk_floor 单调钳制不变）。
3. 记忆摘要只陈述已记录事件（相对日期），绝不虚构、不用诊断词。

## 学科依据（特征 → 依据 → 我们宣称什么）

编号 Rn 指向证据台账 [docs/references/cognition-evidence.md](../references/cognition-evidence.md)，那里有每篇的完整引文、DOI/PMID、**阅读深度**，以及"支撑什么／不支撑什么"。本节的所有表述都已按一手文献核实收窄过，**台账与正文冲突时以台账为准**。

**物理 / 3D 数学**
- 下坠时长闸门（150–2000 ms）：真实跌倒从下降开始到骨盆着地 583 ± 255 ms〔R1〕，而自选速度的起立/坐下约 1.9 s〔R7〕——3–5 倍的**时长**分离，且时间是单目 2D 下唯一未被投影破坏的物理量。→ 我们宣称"下坠时长是否与跌倒假设相容"，不宣称测得速度或冲击力；两个常数本身是我们在该量级内自选的工程值。
- 单目未标定 ⇒ 无度量深度、无绝对速度。空间量一律用**时长与无量纲比值**；质心概念源自环节参数体系〔R10, R11〕，但用单点近似质心跨姿态并不成立〔R12, R13〕，故 B 侧不自造空间量，只解析上游经 evidence 显式提供的比值。→ 永不输出米、米/秒。

**医学（老年科）**
- "long lie"：卧地 >1 小时者半数在 6 个月内死亡〔R15〕；90 岁以上跌倒者 80% 至少一次无法自行起身、30% 曾卧地 ≥1 小时，且 97% 的长躺事件中呼叫器可用却未被按下〔R3〕；无法起身者后续死亡、住院、ADL 下降风险更高〔R5〕；跌后静止时长可预测能否自行起身〔R4〕。→ 跌倒假设后的持续静止是最高优先监测对象（确定性升级链的医学理由）；"呼叫器在手边却没按"也是**主动问候**这一产品形态的直接依据。⚠️ 脱水／压疮／横纹肌溶解常被一并引用，但 R15 一手摘要没有其定量数据，**不得挂在该文名下**。
- 坐立转换能力与跌倒风险相关：五次坐立试验的年龄分层界值〔R16〕、>15 s 使复发跌倒风险翻倍〔R17〕。→ 我们只统计窗口内坐→站转换**次数**作方向一致的粗代理，**不计时、不指定次数，不得声称实现了该量表**。
- 夜尿与跌倒风险相关（每晚 **≥3 次**：RR 1.28〔R18〕；meta 合并 RR 1.20，中等质量〔R19〕）；与骨折的关联未达统计学显著（RR 1.32，95% CI 0.99–1.76，低质量）〔R19〕。→ 夜间时段 + 卫生间上下文的活动片段计入记忆。⚠️ "频次突增是急症前兆"这一说法**未核实到任何一手研究**，已从本 ADR 删除。
- 老年急症常以**行为改变**（跌倒、谵妄、嗜睡、食欲下降）而非典型症状起病：体弱者非典型表现 59% vs 健康老人 25%，且独立预测不良住院结局〔R20〕；UTI 的非典型起病〔R21, R22〕。→ 相对个人基线的偏离比绝对阈值更有信息量，这是记忆层存在的核心理由。（R20 是队列研究，不是共识声明。）

**行为学**
- 行走模式可分型且与认知状态相关：疗养院 5000+ 次行走事件中 direct 86.8%／lapping 11.6%／random 0.9%／pacing 0.7%，直接行走占比与认知状态 r = .56〔R23〕。→ 轨迹级分析因此列为**休眠能力**（需上游经 evidence 提供空间序列）。⚠️ 该文是**行走事件层面**的模式占比，不是把人归为某型；我们的 restlessness_score 只是体位/运动带翻动率，**与该四型无对应关系**。
- 静息-活动节律紊乱与痴呆/MCI 风险前瞻相关（OR 1.57–1.83〔R24〕；UK Biobank 91,517 人，HR 1.14–1.32〔R25〕）。→ 分时段 EWMA 基线是节律画像的极简近似。⚠️ 原研究用腕动计连续测量并计算 M10/L5/相对振幅，**我们的基线不是节律指标，也不做任何风险判断**。
- 自由生活环境下的体位识别显著劣于标准化测试（敏感度 49.9%–99.4%）〔R29〕，且已发表的跌倒检测算法在真实跌倒上灵敏度仅 57.0% ± 27.3%〔R6〕。→ **任何论文准确率都不得移植为 Reme 指标**；系统必须容忍漏检——这正是"先问候、不擅自定性"的设计前提。

**神经科学**
- 精神运动性迟滞（动作减少、启动变慢、活动量下降）是**抑郁**的既有表现〔R26, R27〕。→ 我们只把"活动量持续低于个人基线"作为**问候理由**呈给 MiMo，禁止模型给出任何病名（提示词红线"你不是医生"）。⚠️ 这两篇均为抑郁语境，**不支持**把它作为认知衰退/痴呆的表现，原文该半句已删。

## 不能宣称清单（给 D 的答辩边界，逐条对外有效）

1. 不做医疗诊断、不筛查疾病、不评估认知状态——一切特征只是"值得一句问候/一次告知"的信号。
2. 无度量空间量：没有米、没有速度、没有跌倒冲击力；只有时长与画面内比值。
3. 步态速度、五次坐立等临床量表**没有**被实现——只有方向一致的粗代理。
4. 轨迹级空间智能（房间内路径、行走模式分型）当前为休眠设计，依赖上游未来提供 evidence 空间序列。
5. 记忆是启发式行为画像，不是病历，更不是节律医学指标，不承诺完整或准确。
6. 全屋上下文为通用抽象 + 演示脚本驱动，未接入任何真实家居平台。
7. **不引用任何论文的准确率作为 Reme 的性能承诺**〔R6, R29〕；文献支持的是设计方向，代码里的每个数字要么是我们自选的工程值（台账末表已逐条登记），要么如实标注来源。
8. 不宣称精神运动性迟滞与认知衰退的关联、不宣称夜尿频次突增可预警急症——这两条**没有一手证据**，已从依据中删除。

## 后果

- MiMo 拿到的不再是单帧姿态快照，而是"行为窗口 + 个体基线 + 环境语义"三合一上下文，判断"目的/意图"有了确定性证据链，幻觉空间被进一步压缩（宁缺毋滥守则不变）。
- 三层全部可离线合成、可脚本重放：演示不依赖 A/C 就能讲完整的空间智能故事；A 一旦经 evidence 附带空间线索，休眠超集即时生效。
- 代价：policy 组装提示词的路径变宽，用大样本实验台（`mimo/experiment.py`）对 v1/v2 提示词做分支漂移与 JSON 成功率的回归对比，防止上下文注入反而破坏结构化输出。
