# ADR-0006: 行为语义 · 长期记忆 · 全屋上下文——B 认知增强层的学科依据与边界

- 状态：Accepted（B 域内部决策，不改变 A/B/C 合同任何字段）
- 日期：2026-08-01
- 关联：ADR-0002（衍生运动数据为核心）、ADR-0003（最小视觉上下文）、ADR-0005（先问候、确定性升级、模型不可撤销）

## 背景

B 收到的是 A 的去标识粗粒度流（PostureObservation / TransitionEvent），却要回答一个更高阶的问题：**这个人此刻的行为意味着什么、他想做什么、系统该不该主动介入**——即"基于人物行为与空间变动判断人物目的"的空间智能。约束：

1. 合同冻结，不给 A/C 增加任何义务；
2. 单目未标定摄像头，无深度、无绝对尺度；
3. 隐私优先：原始画面不出户（ADR-0001），B 只碰衍生数据；
4. MiMo 是认知中枢，但升级决定权归确定性规则（ADR-0005）。

## 决策

在 B 内部加三层**确定性**认知上下文，全部注入 MiMo 提示词，并在硬安全界内调制触发阈值：

| 层 | 模块 | 内容 |
|---|---|---|
| 行为语义 | `decision/behavior.py` | 回看窗口的时序特征：体位变化率、静止片段、坐↔站/躺↔起转换、主导体位、跌倒/不确定转换计数；空间线索（下坠时长、质心下降比、落地后残余运动）作为 `TransitionEvent.evidence` 的**休眠超集**解析——有则用，无则零影响 |
| 长期记忆 | `decision/memory.py` | 分时段（0-23 时桶）活动基线 EWMA、里程碑事件史（主诉/跌倒/授权/化解）、今日相对基线的偏离度；持久化 JSON，跨会话累积 |
| 全屋上下文 | `decision/home.py` | 房间语义 × 时刻 × 环境信号（通用抽象，非任何厂商协议）：同一体位在不同上下文含义翻转——凌晨卧室躺=睡觉（阈值放宽 3 倍），卫生间躺=需要问候（阈值减半且 LYING 进入关注体位） |

### 安全不变量（继承并扩展 ADR-0005）

1. 三层只**添加上下文、收紧注意力**；任何一层都不得放松跌倒规则：`fall_confidence_min`、超时、rewind、隐私档位在上下文调制中原样拷贝，静止阈值缩放钳制在 [0.5, 3.0]。
2. 记忆与上下文只进提示词与阈值调制，**不进状态机转移条件**——升级台阶仍由规则独占，MiMo 与记忆都撤销不了已有告警（risk_floor 单调钳制不变）。
3. 记忆摘要只陈述已记录事件（相对日期），绝不虚构、不用诊断词。

## 学科依据（特征 → 依据 → 我们宣称什么）

**物理 / 3D 数学**
- 下坠时长闸门（150ms–2000ms）：失控跌倒是重心的准自由落体，实拍跌倒研究显示从失稳到触地在 1 秒量级内完成（Robinovitch 等对养老机构真实跌倒录像的分析，Lancet 2013）；受控躺下显著更慢，而百毫秒级"下坠"是抖动噪声。→ 我们宣称"下坠动力学是否与跌倒假设相容"，不宣称测得速度或冲击力。
- 单目未标定 ⇒ 无度量深度、无绝对速度。所有空间量一律用**时长与无量纲比值**（质心下降量/画面身高），透视与遮挡误差如实存在。→ 永不输出米、米/秒。

**医学（老年科）**
- "long lie"：跌倒后长时间无法自行起身（文献以 ≥1 小时为界）与脱水、压疮、横纹肌溶解及死亡率显著相关（Wild 等，BMJ 1981 起的经典结论）。→ 跌倒假设后的持续静止是最高优先监测对象；这正是确定性升级链的医学理由。
- 坐立转换能力：五次坐立试验超过 ~12-15 秒提示下肢肌力下降与跌倒风险（老年科常用筛查）。→ 我们只统计窗口内坐→站转换**次数与趋势**作粗代理，不做任何筛查结论。
- 夜尿：每夜 ≥2 次起夜与老年跌倒/骨折风险相关，且频次突增可能是感染等急症的行为前兆（老年医学共识）。→ 夜间时段 + 卫生间上下文的活动片段计入记忆，突增只作为"值得一句问候"的信号。
- 老年急症常以**行为改变**而非典型症状起病（老年医学"非典型表现"教学共识）。→ 相对基线的偏离度（今天比平时静多久）比绝对阈值更有意义，这是记忆层存在的核心理由。

**行为学**
- 痴呆徘徊行为存在可分型的运动模式（Martino-Saltzman 等 1991：直达/踱步/绕圈/随机）。→ 现有合同只支撑 restlessness_score（体位/运动档翻动率）这一粗代理；真正的轨迹分型需要 A 未来经 evidence 超集提供空间序列，故设计为休眠能力。
- 日常节律的稳定性本身是健康指标，静息-活动节律紊乱与认知衰退相关（腕动计文献共识）。→ 分时段 EWMA 基线即节律画像的最小实现。

**神经科学**
- 精神运动性迟滞（psychomotor slowing）是抑郁与认知衰退的公认表现，表现为动作启动变慢、活动量下降。→ 我们只把"活动量持续低于基线"作为**问候理由**呈给 MiMo，明确禁止模型给出任何病名（提示词红线"你不是医生"）。

## 不能宣称清单（给 D 的答辩边界，逐条对外有效）

1. 不做医疗诊断、不筛查疾病、不评估认知状态——一切特征只是"值得一句问候/一次告知"的信号。
2. 无度量空间量：没有米、没有速度、没有跌倒冲击力；只有时长与画面内比值。
3. 步态速度、五次坐立等临床量表**没有**被实现——只有方向一致的粗代理。
4. 轨迹级空间智能（房间内路径、徘徊分型）当前为休眠设计，依赖上游未来提供 evidence 空间序列。
5. 记忆是启发式行为画像，不是病历，不承诺完整或准确。
6. 全屋上下文为通用抽象 + 演示脚本驱动，未接入任何真实家居平台。

## 后果

- MiMo 拿到的不再是单帧姿态快照，而是"行为窗口 + 个体基线 + 环境语义"三合一上下文，判断"目的/意图"有了确定性证据链，幻觉空间被进一步压缩（宁缺毋滥守则不变）。
- 三层全部可离线合成、可脚本重放：演示不依赖 A/C 就能讲完整的空间智能故事；A 一旦经 evidence 附带空间线索，休眠超集即时生效。
- 代价：policy 组装提示词的路径变宽，用大样本实验台（`mimo/experiment.py`）对 v1/v2 提示词做分支漂移与 JSON 成功率的回归对比，防止上下文注入反而破坏结构化输出。
