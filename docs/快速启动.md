# Reme ABC 单机快速启动

## 推荐方式

在仓库根目录执行：

```bash
uv run reme-local-demo
```

也可以执行：

```bash
scripts/start-demo.sh
```

macOS 可双击根目录的 `启动Reme全链路演示.command`。三个入口最终都调用同一个 Python 启动器，不存在两套不同的进程管理逻辑。

启动器会：

1. 检查 8770、8100、4174 是否已有真实监听器。
2. 自动读取 `~/.config/reme/mimo.env`。
3. 缺少前端依赖时执行 `npm install`。
4. 启动 A 感知、B 决策和 C Vite。
5. 等待三个 HTTP 服务就绪。
6. 输出唯一验收地址。
7. 在 `Ctrl+C` 时统一停止三个子进程。

不使用 systemd，前端不由 B 静态托管。

## 验收地址

```text
http://127.0.0.1:4174/typical-demo.html
```

页面默认进入深夜跌倒验收场景。左侧显示现场摄像头、骨架或隐私画面；右侧显示：

- C 浏览器摄像头输入状态；
- A 静态姿态结果；
- A 动作转变结果；
- B 规则与 MiMo 决策；
- 当前 ABC 会话和降级原因。

## MiMo 配置

首次使用可执行：

```bash
scripts/setup-mimo-env.sh
```

也可以手动创建：

```bash
mkdir -p ~/.config/reme
printf '%s\n' 'export MIMO_API_KEY=你的key' > ~/.config/reme/mimo.env
chmod 600 ~/.config/reme/mimo.env
```

没有 MiMo key 时，确定性跌倒询问、倒计时和家属告警仍可运行；语音意图和视觉确认会明确降级。

## 手动三终端方式

仅用于排障。正常验收优先使用一键命令。

A：

```bash
uv run python -m reme.pose.runtime_server \
  --host 127.0.0.1 \
  --port 8770 \
  --input-adapter c_ws_server \
  --browser-input-mode auto
```

B：

```bash
source ~/.config/reme/mimo.env 2>/dev/null || true
uv run reme-decision-server \
  --host 127.0.0.1 \
  --port 8100 \
  --a-events-url ws://127.0.0.1:8770/ws/events
```

C：

```bash
cd frontend
npm run dev -- --host 127.0.0.1 --port 4174 --strictPort
```

## 本地模型资产

MediaPipe wasm 会在 `npm run dev` 和 `npm run build` 前，从 `node_modules` 复制到 `frontend/public/mediapipe/wasm/`。姿态模型位于：

```text
frontend/public/mediapipe/pose_landmarker_lite.task
```

因此页面不再依赖运行时 CDN。模型或 wasm 加载超过 15 秒会显示明确降级，不会一直停留在“连接中”。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示端口已占用 | 8770、8100 或 4174 上存在真实监听器；先关闭旧进程后重试。 |
| 页面无法访问 | 观察启动命令中 `[A]`、`[B]`、`[C]` 前缀日志，确认三个服务都已就绪。 |
| 页面显示等待 ABC 链路 | 刷新页面，并确认 B 健康状态中的 `attached` 和 `connected` 为 `true`。 |
| A 一直是 `starting` | 浏览器尚未获得摄像头权限，或还未发送第一帧。 |
| 摄像头没有画面 | 在浏览器和系统隐私设置中允许摄像头权限。 |
| 有画面但无骨架 | 查看右侧验收面板中的模型错误；本地模型会在 15 秒后明确降级。 |
| 没有 MiMo 决策 | 检查 `~/.config/reme/mimo.env`；规则决策仍应正常工作。 |

## 端口

| 组件 | 地址 | 用途 |
|---|---|---|
| A | `127.0.0.1:8770` | 浏览器输入、姿态和动作转变事件 |
| B | `127.0.0.1:8100` | A 事件订阅、规则/MiMo 决策、危险确认 |
| C | `127.0.0.1:4174` | Vite 验收页面 |
