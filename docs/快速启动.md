# Reme 快速启动（前端 + 后端）

最快方式：**双击仓库根目录的 `启动Reme全链路演示.command`**——它会自动完成下面所有步骤（装依赖 → 读 API 配置 → 起三个服务 → 打开演示页），Ctrl+C 一并停止。以下是分步说明，供手动执行或排障。

## 第一步：装依赖

只需要两个工具：`uv`（Python）和 `node/npm`（前端）。没有就 `brew install uv node`。

```bash
uv sync
```

```bash
cd frontend && npm install
```

- `uv sync` 装后端全部依赖（A 感知 + B 决策都是零第三方运行时依赖，只有开发工具）。
- `npm install` 装前端依赖；之后 `npm run dev` 会自动把 MediaPipe wasm 拷进 `public/`（姿态模型已入库，**全程无需外网 CDN**）。

## 第二步：API 文件配置（MiMo key）

B 的语音意图识别与原图跌倒确认需要 MiMo API key。**没有 key 也能跑**：跌倒询问、预置语音、倒计时、超时升级、家属告警这些规则链路全部可用，只有"语音意图/视觉确认"两条加速路会降级。

1. 到 platform.xiaomimimo.com 用小米账号自助开通（即时生效，无审批）。
2. 创建配置文件（**不要放进仓库**）：

```bash
mkdir -p ~/.config/reme && cat > ~/.config/reme/mimo.env <<'EOF'
export MIMO_API_KEY=在这里粘贴你的key
EOF
chmod 600 ~/.config/reme/mimo.env
```

可选项（有默认值，一般不用写）：`MIMO_BASE_URL`（默认 `https://api.xiaomimimo.com/v1`）、`MIMO_MODEL`（默认 `mimo-v2.5`）。

一键脚本会自动 `source` 这个文件；手动启动 B 之前自己 `source ~/.config/reme/mimo.env` 即可。

## 第三步：启动（手动方式，三个终端）

```bash
uv run python -m reme.pose.runtime_server --host 127.0.0.1 --port 8770
```

```bash
source ~/.config/reme/mimo.env 2>/dev/null; uv run reme-decision-server --port 8100
```

```bash
cd frontend && npm run dev
```

然后浏览器打开：

- 双设备典型场景演示：http://127.0.0.1:4174/typical-demo.html （场景四=真实决策流，右上角亮"B 决策流已接入"）
- 主演示壳（老人端+家属端）：http://127.0.0.1:4174/

## 常见问题

| 现象 | 处理 |
|---|---|
| 页面打不开 | 三个服务哪个没起看日志：`/tmp/reme-a.log`、`/tmp/reme-b.log`、`/tmp/reme-vite.log` |
| 摄像头黑屏 | 必须在真实浏览器（Chrome/Safari）打开并允许摄像头；系统设置→隐私→摄像头给浏览器开权限 |
| 有画面无骨架 | 页面左下角会显示模型加载错误提示（已本地化+15s 超时，不会静默） |
| 场景四右上角是"演示脚本模式" | A 或 B 没起来；起好后刷新页面 |
| 手机访问 | 需 HTTPS（mkcert）+ vite `--host`，见 `.scratch/mimo-decision-interaction/api-for-c.md` 附录 |
