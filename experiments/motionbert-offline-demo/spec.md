# MotionBERT 离线双屏 Demo

- Type: prototype
- Status: measured
- Date: 2026-08-01

## 要回答的问题

能否把现有测试视频和已经提取的 MoveNet 2D 关键点，离线转换成 MotionBERT 三维骨架，并在一个本地 Web 页面中同步展示：

- 左侧：原始视频；
- 右侧：可旋转、缩放的三维骨架和简单空间环境；
- 视频拖动、播放速度和骨架帧严格同步。

## 已接受的 Demo 约束

- 先做离线预计算，不要求浏览器或树莓派实时推断。
- 原视频只由本机 HTTP 服务提供，不上传云端。
- MotionBERT 输出是单目、根节点相对的三维姿态估计，不宣称真实房间坐标、绝对距离或医学级测量。
- 当前复用已验证稳定的 MoveNet 17 点，不再额外引入 AlphaPose 检测链路。
- MoveNet COCO 17 点会按 MMPose 的 COCO→Human3.6M 规则转换为 H36M 17 点。
- Web 展示只消费预计算 JSON；比赛现场不重新运行模型。

## 推断实现

- 模型：MotionBERT DSTFormer，243 帧窗口。
- 权重：OpenMMLab 发布的 MotionBERT finetuned H36M checkpoint。
- 运行：CUDA，FP16 autocast，水平翻转测试增强。
- 长视频：243 帧滑窗、81 帧步长、重叠区加权融合。
- 展示平滑：推断后可选短窗三角平滑，只用于展示。

## 验收条件

1. checkpoint 的全部权重严格映射，无缺失、无意外张量、无形状不匹配。
2. CUDA 前向输出有限值，形状为 `[N, T, 17, 3]`。
3. 目标视频 2370 帧均生成三维骨架。
4. Web 页面可以播放、暂停、拖动，左右视图同步。
5. 可以拖动旋转 3D 场景，提供正视、侧视、俯视和重置视角。
6. 页面明确显示单目根节点相对三维估计的能力边界。

## 2026-08-01 结果

- OpenMMLab checkpoint 的 260/260 个张量严格映射到官方 DSTFormer，无缺失、无意外键、无形状不匹配。
- RTX 2060 CUDA 前向测试通过，243 帧输入输出为 `[1, 243, 17, 3]`，结果全部为有限值。
- 目标视频 2370 帧全部生成三维结果。
- 243 帧窗口、81 帧步长共 28 个窗口，batch size 4，FP16 autocast 与翻转增强开启。
- 完整离线推断约 2.95 秒，有效输出速度约 803 FPS，峰值 CUDA 显存约 682 MB。
- 本地 Web 的视频 Range、元数据、3D JSON、Three.js 模块均通过 HTTP 检查。
- 无头 Chromium 实际执行成功：载入层消失、2370 帧状态写入 DOM、无 JavaScript/WebGL 错误，并生成 1440×1000 页面截图。

结论：离线双屏 Demo 可用。下一步是团队人工观看关键动作片段，确认三维朝向与动作观感，再决定是否调整视角或展示平滑参数。
